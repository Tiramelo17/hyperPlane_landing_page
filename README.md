# HyperPlane AI Landing Page

Landing page em React para apresentar a HyperPlane AI, seus serviços de IA e Machine Learning e canais de contato.

## Scripts

```bash
npm install
npm run dev
npm run build
```

O formulário de contato usa FormSubmit para enviar os dados do lead para `melotechsolu@gmail.com`, evitando custo e infraestrutura de backend. Na primeira submissão, o FormSubmit pode pedir confirmação do e-mail de destino.
